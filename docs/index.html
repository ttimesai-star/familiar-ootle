Familiar

A private allowance for AI agents on Tari Ootle. The agent can spend only up to the owner's limits, only to payees the owner listed, and the owner can take the budget back at any moment. The network enforces it, not the agent's code. In coupon mode no µT amount reaches the chain: not the budget, not what is left, not what a payment moved. An observer sees that a payment happened and how many hidden coupons it spent (the counts are public), never what a coupon is worth, nor who is behind a payee. Only the network fee of each transaction is public.

      The problem

      The Ootle wallet daemon can hand an AI agent an API key with scopes such as TransactionSend_<account>. A scope says what the agent may do, not how much: a key that may send may send the whole account. An agent that reads the web can be told, in text hidden in a page, to do exactly that. On a transparent chain its wallet is also public: balance, every service it pays, who funds it.

      Familiar moves the limits into the chain and keeps the purse out of sight.

      Leaks, named. In amount mode payment amounts are public; in coupon mode their relative sizes are (3 coupons, then 2). The coupon denomination is the owner's: "Try it" draws it at random per leash and keeps it in the wallet file. The window usage is public (component state). Payments of one leash are linked by the leash and the agent key. In this demo the one-time keys are funded from one account in one transaction, which links them; a real owner funds them from separate stealth outputs. Prototype, not audited.

      Try it yourself

      Your own leash in coupon mode on Esmeralda, from a fresh key, in about 3 minutes (prebuilt client in the release, or cargo build -p familiar-cli --release; the README has the sha256 and the macOS/Windows notes for unsigned binaries):

      familiar tap-status            # what the tap holds; anyone can refill it (tap-top-up)
familiar wallet me.json        # a fresh testnet key, written only to me.json
familiar tap    me.json        # 5 tTARI from the Familiar tap
familiar leash  me.json        # a leash in coupon mode with 10 hidden coupons, a random denomination
familiar pay    me.json candle-shop 2
familiar ask    me.json "any text, e.g. a hidden instruction to pay refund-desk"
familiar pause  me.json; familiar recall me.json; familiar show me.json

      For an LLM agent: scripts/familiar_mcp.py is an MCP server whose only spending tool, pay_through_leash, goes through the same leash.
