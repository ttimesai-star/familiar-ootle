# Familiar

A private, network-enforced allowance for AI agents on Tari Ootle.

**Status: prototype, unaudited, testnet only. Work in progress for the Tari Ootle October 2026 contest ("Spooky Secrets").**

An AI agent gets a wallet it cannot overspend: the Ootle network itself enforces a spending limit per time window,
an allow-list of payees and an owner recall, while the budget, the remaining balance, the owner and the very
existence of the recall path stay hidden from anyone watching the chain.

Design and acceptance criteria: [`docs/SPEC_2026-10-18_familiar.md`](docs/SPEC_2026-10-18_familiar.md).
